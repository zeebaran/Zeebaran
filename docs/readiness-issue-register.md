## Preserved verified controls and existing limitations

- Role changes revoke sessions; private page/API read and write checks remain server enforced. No role/session weakening is planned.
- Existing admin navigation optimizations, published/draft separation, bounded queries, cursor ordering, transactions and the local OG/brand assets remain intact.
- Exact `#8cc63f` remains an explicitly accepted contrast failure, not WCAG AA compliance.
- Deletion protection/PITR, restore drills, deployed monitoring, real-account/deployed latency and physical-device/Firefox verification require operational evidence. They are risks or coverage gaps, not newly reproduced application defects.
- Media search filters loaded pages. Full-library indexed search is not assumed or added through an unreviewed live schema migration.
- Optional YouTube poster preparation still awaits external providers during CMS validation. This is a source-identified latency risk; it is not yet credited as a measured production bottleneck or changed without a separate reproduction.
- No unused dependency or asset is approved for deletion merely because a static import scan misses a reference. Migration utilities, fallback PDF intake, dynamic imports, fonts, sketches and original media backups retain their current roles.
